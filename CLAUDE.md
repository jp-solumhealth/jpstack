# jpstack

Claude Code skills for running a healthcare AI startup as a solo CEO.
Pairs with [gstack](https://github.com/garrytan/gstack) for engineering execution.

## THIS REPOSITORY IS PUBLIC

Never commit confidential data here: investor names or terms, ARR / MRR / revenue / burn / runway or any internal financials, pricing or rate cards, customer or prospect names and contacts, call transcripts or quotes, CRM / Notion / Drive IDs, credentials, PHI, or personal finances. Skills that need any of that live in the private repo (`jpstack-private`). Use placeholders like `[Prospect]`, `$[X]`, `<ID>`. The pre-push check `scripts/check-public.sh` must pass.

## Skills

### Founder operating system
| Command | What it does |
|---|---|
| `/chief-of-staff` | Morning briefing from CRM, meetings and outreach |
| `/weekly-review` | Weekly CEO dashboard across pipeline, meetings and outreach |
| `/weekly-retro` | Friday scorecard: revenue pace, deals, calls, outreach, content |
| `/pmf-pulse` | Multi-source PMF intelligence: calls, Reddit, job posts, competitors |
| `/product-insights` | Sprint planning: feature requests, bugs, RICE scores from calls |
| `/icp-research` | Derive or challenge an ICP from evidence |
| `/ops-metrics` | Weekly ops review for a verification or prior-auth team |
| `/team-feedback` | Format feedback for the platform team |

### Sales and events
| Command | What it does |
|---|---|
| `/meeting-prep` | One-page brief before a sales or customer call |
| `/meeting-followup` | Follow-up email, CRM notes and debrief after a call |
| `/win-loss` | Win-loss analysis across deals |
| `/one-pager-builder` | Single-page branded PDF brief for a prospect |
| `/conference-prep` | Pre-event: lead enrichment and curated agenda |
| `/post-conference-insights` | Post-event: branded PDF one-pager |
| `/post-conference-fup` | Post-event: segment contacts, build sequences |
